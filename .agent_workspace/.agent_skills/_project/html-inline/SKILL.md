# HTML 内嵌输出规范（仅限轻量示意图）

## 先判路由（强制，读其它内容前先过这条）

**成品页面一律上应用制作板，禁止内嵌**：演示页 / 类 PPT / 仪表盘 / 数据面板 / 展示页 / 报告页 / 介绍页 / 任何用户想保留、能称之为「一个页面 / 一个应用」的交付物——
调 `create_workflow_board(board_type="html")` 建应用制作板，在看板里写页面文件并发布。

**内嵌 HTML 只用于**：文字回答中顺带的轻量示意——一个小图表、一小段交互演示、帮助理解答案的配图级片段。判断标准：它是「回答的辅助图示」还是「用户要的成品」？成品 = 上板，绝不内嵌。

## 内嵌写法（确认是轻量示意图后）

用 HTML fenced block 直接输出，前端会以内嵌页面的形式渲染在对话流里：

```html
<!DOCTYPE html>
<html>
...完整 HTML...
</html>
```

片段也可以（无 `<html>` 标签），前端会自动补全外层结构。

## 内嵌展示约束

- 这是**内嵌展示**，不是独立页面——body 不要设 `overflow: hidden`，整体高度由内容自动撑开，不要写死 `height`
- 宽度用 `max-width` + `margin: 0 auto` 而非固定像素
- 样式追求视觉精良，与对话区整体风格融洽

## 去 AI 味原则（强制）

凡生成 HTML 必须遵守：

- **禁用满版渐变背景**：不要 `background: linear-gradient(135deg, #667eea, #764ba2)` 这类大块渐变；背景用纯色（白/浅灰/深色）
- **禁用默认蓝紫配色**：主色要根据内容语义选择，不要条件反射地用蓝 `#3b82f6` / 紫 `#8b5cf6`
- **卡片要克制**：阴影最多 `0 1px 4px rgba(0,0,0,.08)`，圆角最多 `8px`；禁止 `box-shadow: 0 20px 60px rgba(0,0,0,.3)` 这类戏剧性阴影
- **排版要有密度**：内容要紧凑；避免每节都是"大居中标题 + 要点列表" 的 PPT 式骨架
- **禁用 Emoji**：页面里任何位置都不用 emoji / 表情符号（📊🚀✅✨🔥 这类是重灾区，一眼 AI）；需要图标时写内联 SVG
- **有设计师感**：结构服务内容，不为"好看"堆砌装饰；想象资深设计师手排，而非 AI 套模板
