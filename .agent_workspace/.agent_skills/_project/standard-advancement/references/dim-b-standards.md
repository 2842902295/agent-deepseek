# 视角 B：相关标准对比

在同一领域或相关标准体系中，评估目标标准的定位与国际接轨程度。

## 数据采集

| 数据项 | 工具 | 参数示例 |
|---|---|---|
| 采标信息 | `standard_query` | 查 `standard_base_info` 的 `adopt_*` 字段（加 `deleted = 0`） |
| 同类标准列表 | `search_candidate_standards` | `keywords='关键词', field='cname'` |
| 同类标准详情 | `standard_query` | `WHERE standard_no IN (...)` |
| 领域采标率 | `standard_query` | 按 `industry` / `std_domain` 聚合统计 |

---

## 检查要点与关注点触发条件

### 1. 国际采标情况

数据来源：`adopt_type`、`adopt_level`、`adopt_no`、`adopt_name`

| 触发条件 | 关注点 |
|---|---|
| 无采标 且 同领域采标率 >50% | 国际接轨不足，该领域普遍有国际对标 |
| 采用程度为 NEQ（非等效） | 与国际标准差异较大，技术路径存在偏离 |

### 2. 领域内同类标准对比

搜索策略：从 `cname` 提取核心关键词 → `search_candidate_standards` → 筛选现行、同级别、近期标准

| 触发条件 | 关注点 |
|---|---|
| 目标标准发布时间是同类中最旧（排倒数 20%） | 时效性落后于同领域其他标准 |
| 技术指标明显低于同类（需读正文对比） | 技术要求宽松，竞争力不足 |
| 未被其他标准引用（检查规范性引用） | 在标准体系中影响力弱 |

### 3. 替代关系

数据来源：`replace_stds`、`target_stds`

| 触发条件 | 关注点 |
|---|---|
| `target_stds` 有值 | 已有新版标准替代，应使用新版 |
| `replace_stds` 有值 但被代替的旧标准仍为"现行" | 与旧版并存，可能造成执行混乱 |

### 4. 领域整体采标水平背景

查询同领域（`industry` / `std_domain`）的采标率作为背景参照

---

## 报告输出

```
#### B. 相关标准对比

**国际采标**
- 采标类型：{IDT/MOD/NEQ/无}
- 对应国际标准：{标准号} {名称}
- [关注点 或 无问题]

**同类标准对比**
- 同类标准：X 篇（列出前 3-5 篇）
- 时效对比：本标准 YYYY，同类范围 YYYY-YYYY
- [关注点 或 无问题]

**替代关系**
- 替代链：{旧标准} → 本标准 → {新标准}
- [关注点 或 无问题]

**领域背景**
- 领域：{industry / std_domain}
- 领域采标率：X%
- [关注点 或 无问题]
```

---

## 注意事项

- 若 `search_candidate_standards` 返回结果过多（>30），按发布时间和相关度筛选前 10 篇
- 技术指标对比需实际读取正文章节（`get_standard_chapters`），不能仅凭标题臆断
- 若无采标但技术路径自主且领先，不应标记为关注点，需在报告中说明"自主技术体系"
