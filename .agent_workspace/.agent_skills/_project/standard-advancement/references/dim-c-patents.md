# 视角 C：相关专利支撑度

评估目标标准背后的专利布局是否支撑其技术先进性。依赖 WebSearch MCP 进行联网检索。

## 数据采集

| 数据项 | 工具 | 搜索词模板 |
|---|---|---|
| 国内专利总量 | WebSearch | `"[关键词]" 专利 中国` |
| 专利类型分布 | WebSearch | `"[关键词]" 发明专利 实用新型` |
| 起草单位专利 | WebSearch | `"[起草单位]" "[关键词]" 专利申请人` |
| 国际专利布局 | WebSearch | `"[英文关键词]" patent PCT EPO USPTO JPO` |
| SEP 声明 | WebSearch | `"[标准编号]" SEP OR 标准必要专利` |
| 标准中的专利声明 | `get_standard_chapters` | `keyword='知识产权' OR '专利'` |

**关键词提取：**
- 从 `cname` 提取核心技术对象词（去掉"技术规范"、"试验方法"等通用词）
- 若有 `ename`，补充英文关键词
- 从 `use_range`（适用范围）、`std_obj`（标准对象）提取核心技术术语

---

## 检查要点与关注点触发条件

### 1. 国内专利布局

| 触发条件 | 关注点 |
|---|---|
| 相关专利数量 <20 件 | 专利支撑薄弱，技术储备不足 |
| 发明专利占比 <30% | 专利质量偏低，实用新型为主 |

### 2. 起草单位专利集中度

| 触发条件 | 关注点 |
|---|---|
| 起草单位持有专利占比 <10% | 核心技术不由起草单位掌握，技术话语权弱 |
| 技术高度分散，无单一主导单位 | 行业碎片化，标准整合难度大 |

### 3. 国际专利布局

| 触发条件 | 关注点 |
|---|---|
| 无 PCT 或国际专利 | 无国际专利布局，海外市场受限 |
| 仅国内专利，未覆盖美/欧/日 | 国际化程度低 |

### 4. 标准必要专利（SEP）

| 触发条件 | 关注点 |
|---|---|
| 有 SEP 声明 但无 FRAND 许可承诺 | 专利许可不透明，可能存在授权风险 |

```
- [关注点 或 无问题]

```

## 降级与数据不足处理

### WebSearch 不可用
- 在报告顶部注明："WebSearch 不可用，专利维度暂无数据"

### 搜索结果不足（<3 条有效结果）
- 在报告中注明："专利数据有限，以下分析仅供参考"

---

## 注意事项

- WebSearch 结果是摘要性信息，**不等同于完整专利检索**，报告中必须注明"数据来源于网络搜索"
- 专利数量为估算值，用"约 X 件"表述
- 起草单位名称需规范化处理（去掉"有限公司"、"股份"等后缀）再搜索
- SEP 搜索结果常为零，不应因此简单标记为关注点，需说明"SEP 机制在该领域应用较少"
