# step3-conditions — 识别并收集通用试验条件

## 识别方法

扫描目录，查找标题含以下关键词的章节：

- 试验条件、检验条件、测试条件
- 试验环境、一般条件、通用条件

## 若存在

立即读取该章节全文，将其中所有条件参数原样汇总为**通用试验条件清单**：

```
通用试验条件（来自条款 X.X）：
- 温度：23℃±2℃
- 湿度：45%~75%
- 介质：蒸馏水
- 预处理：在标准环境下放置 24h
```

## 使用规则

- 此清单在第4步提取每个动态指标时都要检查
- 若该试验属于需遵循通用条件的范围，将整份清单并入该指标的 `source_input_params`
- 同时在 `source_clause` 中附上通用条件所在条款编号（如原条款为"5.1"，通用条件在"4.1"，则填 `"4.1,5.1"`）

## 若不存在

本步骤跳过，直接进入第4步。

> **注意**：通用试验条件章节本身不产生任何独立指标，只作为其他动态指标的输入参数来源。
